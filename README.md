# PolyGen AI – Generative Text-to-3D Asset Pipeline

PolyGen AI is a Generative AI-powered platform designed to transform natural language prompts into optimized, textured 3D assets for gaming, VR, AR, and spatial computing applications.

## Core Features

- Text-to-3D asset generation
- AI-powered texture synthesis
- Automated UV mapping
- 3D mesh cleaning and optimization
- Interactive browser-based 3D visualization
- PBR material support
- GLB/GLTF asset export

## Technology Stack

### AI & Backend
- Python
- TripoSR / Shap-E
- Stable Diffusion
- ControlNet
- FastAPI

### 3D Processing
- Trimesh
- Open3D
- UV Mapping
- Quadric Error Metrics (QEM)

### Frontend
- React
- Three.js
- React Three Fiber
